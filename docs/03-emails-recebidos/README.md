# 03 · E-mails Recebidos

Respostas e comunicações **recebidas** de Cris, Gio, Fábio ou qualquer stakeholder.

**Padrão de nome:** `YYYY-MM-DD-remetente-assunto.md`
(exemplo: `2026-07-15-cris-respostas-briefing.md`)

**Cabeçalho mínimo:**
- Data + hora
- De / Para / CC
- Assunto exato
- Corpo (colar como recebido)

Sempre que o e-mail responder o briefing, também **atualizar** `docs/04-respostas-clientes/respostas-briefing.md`.

# 01 · Transcrições de Reunião

Coloque aqui **cada transcrição bruta + notas** de uma reunião com Cris/Gio (ou qualquer stakeholder).

**Padrão de nome:** `YYYY-MM-DD-titulo.md`

**Estrutura sugerida de cada arquivo:**
1. Cabeçalho: data, participantes, duração, contexto.
2. Seção "Pontos-chave extraídos" (o que importa).
3. Seção "Transcrição completa (bruto)" em bloco de código.

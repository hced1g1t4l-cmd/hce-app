### 3. O que é SaaS?

SaaS significa Software as a Service ("Software como Serviço"). É o modelo em que o cliente assina (paga mensal ou anual) para usar um serviço digital, em vez de comprar uma vez. Exemplos:

- **Netflix, Spotify** — paga por mês para ter acesso a conteúdo.
- **Duolingo** — versão gratuita limitada + versão premium paga.
- **Canva, iFood para restaurantes, Notion** — todos são SaaS.

A grande vantagem é a receita recorrente. Você acorda todo dia com dinheiro entrando, sem precisar vender nada novo. É o "dinheiro trabalhando para você" que falei na reunião. O contraste é a consultoria/treinamento tradicional — bom, paga as contas, mas tem teto e depende de vocês estarem disponíveis.

O Clube HCE é um SaaS onde vocês transformam o conhecimento acumulado (fichas técnicas, dicas, aulas) em um produto que escala para o Brasil inteiro.
